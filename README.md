# Mebea — уютно дома

Статический сайт мебельной компании Mebea. В проекте нет сборщика и внешних библиотек: сайт можно публиковать через Railway, GitHub Pages или любой статический хостинг.

## Структура

- `index.html` — главная страница с навигацией, направлениями, услугами, сроками, стоимостью и контактами.
- `project.html` — универсальная страница направления с каталогом объектов. Открывается с параметром, например `project.html?project=kitchens` или `project.html?project=cabinets`.
- `styles.css` — основные адаптивные стили и тёплая цветовая палитра.
- `project.css` — стили страниц проектов и карточек каталога.
- `script.js` — меню и раскрытие описаний карточек.
- `server.js` — небольшой сервер на Node.js для Railway.
- `assets/images/` — папка для фотографий; список имён находится в её `README.md`.

## Как добавлять новые объекты

На странице `project.html` найдите массив `objects` нужного направления и добавьте ещё одну запись с полями `name`, `description`, `price` и `image`. Для нового направления добавьте отдельный ключ в объект `projects`, затем создайте ссылку на него в `index.html`.

## Что заменить перед публикацией

1. Добавить фотографии в `assets/images/` по именам из `assets/images/README.md`.
2. Проверить контакты и при необходимости заменить шаблонные WhatsApp, MAX и e-mail.
3. При необходимости изменить тексты и сроки в HTML.

## Публикация на Railway

1. Создайте репозиторий на GitHub и загрузите туда файлы проекта.
2. Откройте Railway и войдите через GitHub.
3. Выберите **New Project → Deploy from GitHub Repo**, затем нужный репозиторий.
4. Railway автоматически установит Node.js и запустит команду `npm start` из `package.json`.
5. Откройте настройки сервиса в Railway, выберите **Settings → Networking → Generate Domain**.
6. Нажмите на созданный домен — это адрес сайта. Railway сам передаст приложению переменную `PORT`, вручную её задавать не нужно.

После каждого push в выбранную ветку Railway будет автоматически пересобирать и публиковать сайт.
