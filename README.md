# Mebea — уютно дома

Статический сайт мебельной компании Mebea. Проект не использует сборщик или внешние библиотеки, поэтому готов к публикации на GitHub Pages.

## Структура

- `index.html` — главная страница с навигацией, проектами, услугами, сроками, стоимостью и контактами.
- `project.html` — универсальная страница направления. Открывается с параметром, например `project.html?project=kitchens`.
- `styles.css` — основные адаптивные стили и тёплая цветовая палитра.
- `project.css` — стили страниц проектов.
- `script.js` — меню и раскрытие описаний карточек.
- `assets/images/` — папка для фотографий; список имён находится в её `README.md`.

## Что нужно заменить перед публикацией

1. Добавить фотографии в `assets/images/` по именам из `assets/images/README.md`.
2. Заменить шаблонные телефон, WhatsApp, MAX и e-mail в `index.html`.
3. При необходимости изменить тексты, цены и сроки в HTML.
4. Заменить placeholder приветственного логотипа в блоке `.welcome-placeholder` на собственный логотип или фразу.

## Публикация на GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите публикацию из ветки `main` и папки `/ (root)`. После сохранения GitHub Pages будет отдавать `index.html` как главную страницу.
